### 2.2 Polar Triangle Degeneracy in `add_ellipsoid()`

In `src/morphomesh/creature_generator.py` lines 464–492:
```python

    for r in range(rings + 1):
        theta = math.pi * r / rings

            idx = len(verts)

            faces.append((i0, i2, i3))
```

#### Defect Mechanism:
1. At North Pole ($r = 0$): $\theta = 0 \implies \sin\theta = 0$. All `sectors` vertices in `ring_indices[0]` are identical: $(cx, cy, cz + rz)$.
   - Triangle $(i_0, i_2, i_3)$ has $i_0 = i_3$, so edge vector $v_3 - v_0 = (0, 0, 0)$. Area is identically $0.0$.
2. At South Pole ($r = rings - 1$): $\theta = \pi \implies \sin\theta = 0$. All `sectors` vertices in `ring_indices[rings]` are identical: $(cx, cy, cz - rz)$.
   - Triangle $(i_0, i_1, i_2)$ has $i_1 = i_2$, so edge vector $v_2 - v_1 = (0, 0, 0)$. Area is identically $0.0$.
3. With `sectors = 6`, each ellipsoid produces $2 \times 6 = 12$ zero-area triangles.
4. Across the 33 ellipsoids executed in `get_blender_generation_script()`:
   - Torso: 4 ellipsoids (torso core, shoulder hump, mid torso, pelvic torso)
   - Left limbs & paw pads: 12 ellipsoids (1 palmar/plantar sole + 5 digital pads $\times$ 2 front/hind)
   - Right limbs & paw pads: 12 ellipsoids
   - Head: 5 ellipsoids (cranium dome + 2 eyes + 2 ears)
   - Total runtime ellipsoids: $4 + 12 + 12 + 5 = 33$.
   - Total degenerate triangles: $33 \times 12 = \mathbf{396}$.

#### Formulation of the Polar Triangle Fan Fix:
1. **Single North Pole Apex**:
   Add exactly one vertex at $(cx, cy, cz + rz)$ with index `north_idx`.
2. **Intermediate Rings Only**:
   Sample $r \in [1, rings - 1]$. For `rings = 4`, this creates intermediate rings at $r=1, 2, 3$ ($\theta = \pi/4, \pi/2, 3\pi/4$).
3. **Single South Pole Apex**:
   Add exactly one vertex at $(cx, cy, cz - rz)$ with index `south_idx`.
4. **North Triangle Fan**:
   Connect `north_idx` to `ring_indices[0]` using:
   `faces.append((north_idx, ring_indices[0][s], ring_indices[0][next_s]))`
   - Proof of outward orientation: Midpoint centroid has $Z > 0$. Cross product normal has $Z = \sin^2\theta \sin(2\pi/sectors) > 0$. $N \cdot \hat{n}_{\text{radial}} = +1.00$.
5. **Intermediate Quad Bands**:
   For $r \in [0, \text{len}(ring\_indices) - 2]$:
   `faces.append((i0, i1, i2))` and `faces.append((i0, i2, i3))`
   - Standard quad triangulation: outward normal $N \cdot \hat{n}_{\text{radial}} > +0.95$.
6. **South Triangle Fan**:
   Connect `ring_indices[-1]` to `south_idx` using:
   `faces.append((last_ring[s], south_idx, last_ring[next_s]))`
   - Proof of outward orientation: Midpoint centroid has $Z < 0$. Cross product normal points in $-Z$. $N \cdot \hat{n}_{\text{radial}} = +1.00$.

#### Topological Invariants Preserved:
- Euler characteristic: $V - E + F = 20 - 54 + 36 = 2$ (exact manifold closed sphere).
- Watertight: 0 boundary edges, 0 non-manifold edges.
- Zero degenerate faces: all 36 triangles have $area \ge 0.2400 \gg 1e-9$.

### Dynamic Extraction Oracle Fix
The test is refactored to dynamically extract and execute `add_box` from `get_blender_generation_script()`:
```python
def test_blender_generation_script_box_inversions():
    """Assert zero inverted box faces in get_blender_generation_script()."""
    cx, cy, cz = 0.0, 0.0, 0.0
    sx, sy, sz = 1.0, 1.0, 1.0
    corners = [
        np.array([cx - sx, cy - sy, cz - sz]),  # 0
        np.array([cx + sx, cy - sy, cz - sz]),  # 1
        np.array([cx + sx, cy + sy, cz - sz]),  # 2
        np.array([cx - sx, cy + sy, cz - sz]),  # 3
        np.array([cx - sx, cy - sy, cz + sz]),  # 4
        np.array([cx + sx, cy - sy, cz + sz]),  # 5
        np.array([cx + sx, cy + sy, cz + sz]),  # 6
        np.array([cx - sx, cy + sy, cz + sz]),  # 7
    ]

    # Dynamically extract add_box from get_blender_generation_script()
    script = get_blender_generation_script()
    box_part = "def add_box" + script.split("def add_box")[1].split("def add_ellipsoid")[0]
    local_env = {"verts": [], "faces": [], "vgs": {}}
    exec(box_part, local_env)
    local_env["add_box"]((0.0, 0.0, 0.0), (2.0, 2.0, 2.0))
    faces = local_env["faces"]
    assert len(faces) == 12

    expected_face_dirs = [
        ("bottom", np.array([0.0, 0.0, -1.0])),
        ("bottom", np.array([0.0, 0.0, -1.0])),
        ("top", np.array([0.0, 0.0, 1.0])),
        ("top", np.array([0.0, 0.0, 1.0])),
        ("back", np.array([0.0, -1.0, 0.0])),
        ("back", np.array([0.0, -1.0, 0.0])),
        ("front", np.array([0.0, 1.0, 0.0])),
        ("front", np.array([0.0, 1.0, 0.0])),
        ("left", np.array([-1.0, 0.0, 0.0])),
        ("left", np.array([-1.0, 0.0, 0.0])),
        ("right", np.array([1.0, 0.0, 0.0])),
        ("right", np.array([1.0, 0.0, 0.0])),
    ]

    inverted_script_faces = []
    for (i0, i1, i2), (face_name, expected_outward) in zip(faces, expected_face_dirs):
        v0, v1, v2 = corners[i0], corners[i1], corners[i2]
        cross = np.cross(v1 - v0, v2 - v0)
        fn = cross / np.linalg.norm(cross)
        dot = np.dot(fn, expected_outward)
        if dot < -0.5:
            inverted_script_faces.append((face_name, (i0, i1, i2), dot))

    assert len(inverted_script_faces) == 0, (
        f"Found {len(inverted_script_faces)}/12 box triangles in "
        f"get_blender_generation_script() with inverted winding order!"
    )
```
