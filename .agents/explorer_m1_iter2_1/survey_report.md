## 2. Root Cause Analysis

### 2.1 Polar Ring Geometry in `inference_adapter.py`
In `add_sphere()` (lines 224–247) and `add_ellipsoid()` (lines 279–309), vertices are generated on a spherical coordinate grid:
$$\theta_r = \frac{\pi \cdot r}{rings}, \quad \phi_s = \frac{2\pi \cdot s}{sectors}$$

For latitude index $r = 0$:
$$\theta_0 = 0 \implies \sin(\theta_0) = 0, \quad \cos(\theta_0) = 1$$
$$px(s) = cx, \quad py(s) = cy, \quad pz(s) = cz + rz \quad \forall s \in [0, sectors]$$
All $sectors + 1$ vertices in `ring_indices[0]` have the exact same spatial position $(cx, cy, cz + rz)$.

For latitude index $r = rings$:
$$\theta_{rings} = \pi \implies \sin(\theta_{rings}) = 0, \quad \cos(\theta_{rings}) = -1$$
$$px(s) = cx, \quad py(s) = cy, \quad pz(s) = cz - rz \quad \forall s \in [0, sectors]$$
All $sectors + 1$ vertices in `ring_indices[rings]` have the exact same spatial position $(cx, cy, cz - rz)$.

### 2.2 Quad Triangulation Collapse
Lines 249–256 and 311–318 generate quads across all ring intervals $r \in [0, rings - 1]$:
```python
for r in range(rings):
    for s in range(sectors):
        i0 = ring_indices[r][s]
        i1 = ring_indices[r + 1][s]
        i2 = ring_indices[r + 1][s + 1]
        i3 = ring_indices[r][s + 1]
        self.add_quad(i0, i1, i2, i3)
```
Where `add_quad` splits the quad into two triangles:
$$\Delta_1 = (i_0, i_1, i_2), \quad \Delta_2 = (i_0, i_2, i_3)$$

- **At North Pole ($r = 0$)**:
  Vertices $i_0$ and $i_3$ are both on the north polar ring:
  $$v_0 = v_3 = (cx, cy, cz + rz)$$
  In $\Delta_2 = (i_0, i_2, i_3)$, two vertices are identical ($v_0 = v_3$). Its area is:
  $$\text{Area}(\Delta_2) = \frac{1}{2} \|(v_2 - v_0) \times (v_3 - v_0)\| = \frac{1}{2} \|(v_2 - v_0) \times \vec{0}\| = 0.0$$
  This produces 1 zero-area face per sector.

- **At South Pole ($r = rings - 1$)**:
  Vertices $i_1$ and $i_2$ are both on the south polar ring:
  $$v_1 = v_2 = (cx, cy, cz - rz)$$
  In $\Delta_1 = (i_0, i_1, i_2)$, two vertices are identical ($v_1 = v_2$). Its area is:
  $$\text{Area}(\Delta_1) = \frac{1}{2} \|(v_1 - v_0) \times (v_2 - v_0)\| = \frac{1}{2} \|(v_1 - v_0) \times (v_1 - v_0)\| = 0.0$$
  This produces 1 zero-area face per sector.

Total degenerate faces per ellipsoid = $2 \times sectors$.

## 3. Mathematical Verification of Winding Order

### 3.1 Refutation of Challenger M1-2's Winding Suggestion
In `handoff.md` Section 4, Challenger M1-2 suggested:
- North Pole: `add_triangle(pole_idx, ring_1[next_s], ring_1[s])`
- South Pole: `add_triangle(ring_last[s], ring_last[next_s], south_pole_idx)`

Let us compute the surface normal cross product for Challenger's North Pole proposal:
Let $v_0 = (0, 0, 1)$ (North Pole apex).
Let $v_1 = (\sin(\theta_1)\cos(\phi_{s+1}), \sin(\theta_1)\sin(\phi_{s+1}), \cos(\theta_1))$.
Let $v_2 = (\sin(\theta_1)\cos(\phi_s), \sin(\theta_1)\sin(\phi_s), \cos(\theta_1))$.

With $\theta_1 = \pi/4$, $s=0$ ($\phi_0=0$), $s+1=1$ ($\phi_1=\pi/2$):
$$v_0 = (0, 0, 1)$$
$$v_1 = (0, \sin(\pi/4), \cos(\pi/4)) = (0, 0.707, 0.707)$$
$$v_2 = (\sin(\pi/4), 0, \cos(\pi/4)) = (0.707, 0, 0.707)$$

Cross product $(v_1 - v_0) \times (v_2 - v_0)$:
$$e_1 = v_1 - v_0 = (0, 0.707, -0.293)$$
$$e_2 = v_2 - v_0 = (0.707, 0, -0.293)$$
$$e_1 \times e_2 = (-0.207, -0.207, -0.500)$$

The centroid of this triangle is in the first octant ($X > 0, Y > 0, Z > 0$):
$$\vec{C} = \frac{v_0 + v_1 + v_2}{3} \approx (0.236, 0.236, 0.805)$$
$$(e_1 \times e_2) \cdot \vec{C} = (-0.207)(0.236) + (-0.207)(0.236) + (-0.500)(0.805) = -0.500 < 0$$

**The normal points INWARD into the sphere interior!**
Challenger M1-2 reversed the winding order.

### 3.2 Correct Outward Winding Formula
To obtain an outward normal, the triangle winding viewed from the exterior must be counter-clockwise:

1. **North Pole Triangle Fan**:
   $$\Delta_{\text{north}}(s) = (north\_idx, intermediate\_rings[0][s], intermediate\_rings[0][s + 1])$$
   Cross product:
   $$e_1 = intermediate\_rings[0][s] - north\_idx$$
   $$e_2 = intermediate\_rings[0][s+1] - north\_idx$$
   $$e_1 \times e_2 = (+0.207, +0.207, +0.500)$$
   $$(e_1 \times e_2) \cdot \vec{C} = +0.500 > 0 \quad (\textbf{OUTWARD})$$

2. **Intermediate Quad Bands ($r \in [0, len - 2]$)**:
   $$i_0 = ring[r][s], \quad i_1 = ring[r+1][s], \quad i_2 = ring[r+1][s+1], \quad i_3 = ring[r][s+1]$$
   $$\text{add\_quad}(i_0, i_1, i_2, i_3) \implies (i_0, i_1, i_2) \text{ and } (i_0, i_2, i_3)$$
   Both triangles yield dot product $+0.707 > 0$ with the surface centroid ($\textbf{OUTWARD}$).

3. **South Pole Triangle Fan**:
   $$\Delta_{\text{south}}(s) = (intermediate\_rings[-1][s], south\_idx, intermediate\_rings[-1][s + 1])$$
   $$\text{or cyclically: } (south\_idx, intermediate\_rings[-1][s + 1], intermediate\_rings[-1][s])$$
   Cross product:
   $$e_1 = south\_idx - intermediate\_rings[-1][s]$$
   $$e_2 = intermediate\_rings[-1][s+1] - intermediate\_rings[-1][s]$$
   $$e_1 \times e_2 = (+0.207, +0.207, -0.500)$$
   Centroid has negative $Z$: $\vec{C} \approx (0.236, 0.236, -0.805)$.
   $$(e_1 \times e_2) \cdot \vec{C} = (+0.207)(0.236) + (+0.207)(0.236) + (-0.500)(-0.805) = +0.500 > 0 \quad (\textbf{OUTWARD})$$

```python
    def add_sphere(
        self,
        center: Tuple[float, float, float],
        radius: float,
        rings: int = 12,
        sectors: int = 16,
    ) -> None:
        """Add a UV sphere with outward normals and polar triangle fans."""
        cx, cy, cz = center
        rings = max(2, rings)
        sectors = max(3, sectors)

        # 1. Single North Polar vertex
        north_idx = self.add_vertex((cx, cy, cz + radius), (0.0, 0.0, 1.0), (0.5, 0.0))

        # 2. Intermediate latitude rings (r = 1 to rings - 1)
        intermediate_rings: List[List[int]] = []
        for r in range(1, rings):
            theta = math.pi * r / rings
            sin_t = math.sin(theta)
            cos_t = math.cos(theta)
            v = r / rings
            current_ring = []

            for s in range(sectors + 1):
                phi = 2.0 * math.pi * s / sectors
                sin_p = math.sin(phi)
                cos_p = math.cos(phi)
                u = s / sectors

                nx = sin_t * cos_p
                ny = sin_t * sin_p
                nz = cos_t

                px = cx + radius * nx
                py = cy + radius * ny
                pz = cz + radius * nz

                idx = self.add_vertex((px, py, pz), (nx, ny, nz), (u, v))
                current_ring.append(idx)
            intermediate_rings.append(current_ring)

        # 3. Single South Polar vertex
        south_idx = self.add_vertex((cx, cy, cz - radius), (0.0, 0.0, -1.0), (0.5, 1.0))

        # 4. North Polar triangle fan
        for s in range(sectors):
            self.add_triangle(north_idx, intermediate_rings[0][s], intermediate_rings[0][s + 1])

        # 5. Intermediate latitude quad bands
        for r in range(len(intermediate_rings) - 1):
            for s in range(sectors):
                i0 = intermediate_rings[r][s]
                i1 = intermediate_rings[r + 1][s]
                i2 = intermediate_rings[r + 1][s + 1]
                i3 = intermediate_rings[r][s + 1]
                self.add_quad(i0, i1, i2, i3)

        # 6. South Polar triangle fan
        for s in range(sectors):
            self.add_triangle(intermediate_rings[-1][s], south_idx, intermediate_rings[-1][s + 1])
```

    def add_ellipsoid(
        self,
        center: Tuple[float, float, float],
        radii: Tuple[float, float, float],
        rings: int = 8,
        sectors: int = 12,
    ) -> List[int]:
        """Add an axis-oriented 3D ellipsoid with outward normals and polar triangle fans."""
        cx, cy, cz = center
        rx, ry, rz = radii
        rings = max(2, rings)
        sectors = max(3, sectors)
        added_indices: List[int] = []

        # 1. Single North Polar vertex
        north_idx = self.add_vertex((cx, cy, cz + rz), (0.0, 0.0, 1.0), (0.5, 0.0))
        added_indices.append(north_idx)

        # 2. Intermediate latitude rings (r = 1 to rings - 1)
        intermediate_rings: List[List[int]] = []
        for r in range(1, rings):
            theta = math.pi * r / rings
            sin_t = math.sin(theta)
            cos_t = math.cos(theta)
            v = r / rings
            current_ring = []

            for s in range(sectors + 1):
                phi = 2.0 * math.pi * s / sectors
                sin_p = math.sin(phi)
                cos_p = math.cos(phi)
                u = s / sectors

                nx = sin_t * cos_p
                ny = sin_t * sin_p
                nz = cos_t

                px = cx + rx * nx
                py = cy + ry * ny
                pz = cz + rz * nz

                nnx = nx / rx if rx > 1e-6 else 0.0
                nny = ny / ry if ry > 1e-6 else 0.0
                nnz = nz / rz if rz > 1e-6 else 0.0
                n_len = math.sqrt(nnx * nnx + nny * nny + nnz * nnz)
                norm = (nnx / n_len, nny / n_len, nnz / n_len) if n_len > 1e-6 else (nx, ny, nz)

                idx = self.add_vertex((px, py, pz), norm, (u, v))
                current_ring.append(idx)
                added_indices.append(idx)
            intermediate_rings.append(current_ring)

        # 3. Single South Polar vertex
        south_idx = self.add_vertex((cx, cy, cz - rz), (0.0, 0.0, -1.0), (0.5, 1.0))
        added_indices.append(south_idx)

        # 4. North Polar triangle fan
        for s in range(sectors):
            self.add_triangle(north_idx, intermediate_rings[0][s], intermediate_rings[0][s + 1])

        # 5. Intermediate latitude quad bands
        for r in range(len(intermediate_rings) - 1):
            for s in range(sectors):
                i0 = intermediate_rings[r][s]
                i1 = intermediate_rings[r + 1][s]
                i2 = intermediate_rings[r + 1][s + 1]
                i3 = intermediate_rings[r][s + 1]
                self.add_quad(i0, i1, i2, i3)

        # 6. South Polar triangle fan
        for s in range(sectors):
            self.add_triangle(intermediate_rings[-1][s], south_idx, intermediate_rings[-1][s + 1])

        return added_indices

def add_ellipsoid(center, radii, rings=4, sectors=6, group_name=None):
    cx, cy, cz = center
    rx, ry, rz = radii
    s_idx = len(verts)
    rings = max(2, rings)
    sectors = max(3, sectors)

    # 1. North pole vertex
    north_idx = len(verts)
    verts.append((cx, cy, cz + rz))

    # 2. Intermediate rings
    intermediate_rings = []
    for r in range(1, rings):
        theta = math.pi * r / rings
        sin_t, cos_t = math.sin(theta), math.cos(theta)
        c_ring = []
        for s in range(sectors):
            phi = 2.0 * math.pi * s / sectors
            px = cx + rx * sin_t * math.cos(phi)
            py = cy + ry * sin_t * math.sin(phi)
            pz = cz + rz * cos_t
            idx = len(verts)
            verts.append((px, py, pz))
            c_ring.append(idx)
        intermediate_rings.append(c_ring)

    # 3. South pole vertex
    south_idx = len(verts)
    verts.append((cx, cy, cz - rz))

    # 4. North pole fan
    for s in range(sectors):
        next_s = (s + 1) % sectors
        faces.append((north_idx, intermediate_rings[0][s], intermediate_rings[0][next_s]))

    # 5. Intermediate quads
    for r in range(len(intermediate_rings) - 1):
        for s in range(sectors):
            next_s = (s + 1) % sectors
            i0 = intermediate_rings[r][s]
            i1 = intermediate_rings[r + 1][s]
            i2 = intermediate_rings[r + 1][next_s]
            i3 = intermediate_rings[r][next_s]
            faces.append((i0, i1, i2))
            faces.append((i0, i2, i3))

    # 6. South pole fan
    for s in range(sectors):
        next_s = (s + 1) % sectors
        faces.append((intermediate_rings[-1][s], south_idx, intermediate_rings[-1][next_s]))

    new_indices = list(range(s_idx, len(verts)))
    if group_name and group_name in vgs:
        vgs[group_name].extend(new_indices)
