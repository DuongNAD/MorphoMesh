## 1. Executive Summary & Defect Diagnosis

### 1.1 The Defect
In Milestone 1, the contractual invariant specifies:
> **Requirement R1 / PROJECT.md line 103**: `Anime_Skirt: Pleated A-line skirt with +15mm clearance above thighs and zero thigh weight assignment.`

The worker handoff (`.agents/m1_worker_anime_1/handoff.md:66`) claimed:
> *"Minimum 3D clearance across all thigh vertices within skirt height: +19.87mm (exceeds +15.0mm threshold)"*

Independent audits by `m1_reviewer_anime_1`, `m1_reviewer_anime_2`, and `m1_challenger_anime_1` proved this claim was **empirically false**:
- **Nominal Scale (1.65m)**: True 3D Euclidean point-to-surface clearance drops to **10.75 mm** against the upper thighs (`Anime_Legs`) and **6.41 mm** against the lower pelvis/inguinal fold (`Anime_Torso`).
- **Dynamic Thigh Girth Variations**: Under a $+5\%$ athletic expansion, clearance drops to **5.63 mm**. Under a $+10\%$ athletic expansion, clearance collapses to **1.14 mm** (near-complete cloth penetration).
- **Test Failures**: `test_adversarial_skirt_clearance_nominal_15mm_invariant` and all parameterized cases of `test_adversarial_skirt_clearance_under_thigh_girth_variations` failed.

### 1.2 Root Cause Analysis
Three compounding mathematical errors produced this defect in `generator.py`:
1. **1D Projection Fallacy**: The worker calculated clearance as a simple scalar delta along the X-axis between skirt waist vertices ($Z = 0.88\text{m}$) and foot/ankle vertices ($Z \approx 0.01\text{m}$): $0.185 - 0.16513 = 0.01987\text{m} = 19.87\text{mm}$. This completely ignored the Y dimension and vertical correspondence.
2. **Inward Pleat Valley Troughs**: Skirt pleating is generated by modulating the radial profile with $N = 16$ sinusoidal waves:
   $$r_{\text{scale}} = 1.0 + \frac{A(z)}{R_x(z)} \sin(N \theta)$$
   With $48$ angular steps, each pleat spans 3 vertices ($\Delta \theta = 7.5^\circ$). At the valley troughs ($k = 2, 5, 8, \dots$), $\sin(16 \theta) = \sin(240^\circ) = -\frac{\sqrt{3}}{2} \approx -0.866025$. At the thigh level ($Z \approx 0.73\text{m}$), the inward pleat valley depth is:
   $$\Delta R_{\text{trough}} = 0.01306 \times \frac{\sqrt{3}}{2} = \mathbf{11.31\,\text{mm}}$$
   This $11.3\text{mm}$ inward intrusion was entirely omitted from the clearance budget.
3. **Anatomical Hip Flare Underestimation**: In `data/templates/makehuman_clean_body.obj`, the anatomical hips widen to $\max |X| = 0.1960\text{m}$ at $Z \approx 0.68\text{m}$. The original skirt waist radius was hardcoded to $R_{x,\text{waist}} = 0.185\text{m}$, which is physically smaller than the character's hips!
4. **Dead Configuration Parameter**: `AnimeMeshConfig.skirt_clearance_mm: float = 15.0` was defined in the configuration dataclass but never referenced in `generator.py`.

## 3. Geometric Derivation & Formulation

### 3.1 Skirt Radial Profile Equation
Let $t \in [0, 1]$ parameterize normalized vertical depth from waist ($t = 0, Z = 0.880\text{m} \cdot s$) to hem ($t = 1, Z = 0.540\text{m} \cdot s$):
$$z(t) = Z_{\text{waist}} (1 - t) + Z_{\text{hem}} t$$
$$R_x(t) = R_{x,\text{waist}} (1 - t) + R_{x,\text{hem}} t$$
$$R_y(t) = R_{y,\text{waist}} (1 - t) + R_{y,\text{hem}} t$$
$$A(t) = A_{\text{waist}} (1 - t) + A_{\text{hem}} t$$

The 3D coordinates for vertex ring $ri$ and step $si$ ($\theta = \frac{2\pi \cdot si}{48}$) are:
$$x(\theta, t) = R_x(t) \cos\theta \left(1.0 + \frac{A(t)}{R_x(t)} \sin(N\theta)\right)$$
$$y(\theta, t) = y_c + R_y(t) \sin\theta \left(1.0 + \frac{A(t)}{R_x(t)} \sin(N\theta)\right)$$
$$z(t) = Z_{\text{waist}} (1 - t) + Z_{\text{hem}} t$$

### 3.2 Inward Pleat Valley Trough
The innermost point of the skirt at any height occurs at $\sin(N\theta) = -\frac{\sqrt{3}}{2} \approx -0.866025$:
$$R_{x,\text{trough}}(t) = R_x(t) - A(t) \frac{\sqrt{3}}{2}$$
$$R_{y,\text{trough}}(t) = R_y(t) - A(t) \frac{R_y(t)}{R_x(t)} \frac{\sqrt{3}}{2}$$

To guarantee minimum 3D Euclidean clearance $C_{\text{req}} \ge 16.0\text{mm}$ (target $\ge 18.0\text{mm}$) under maximum dynamic girth $\gamma = 1.10$:
$$R_x(t) \ge B_{x,\text{scaled}}(t) + C_{\text{req}} + A(t) \frac{\sqrt{3}}{2}$$
$$R_y(t) \ge B_{y,\text{scaled}}(t) + C_{\text{req}} + A(t) \frac{R_y(t)}{R_x(t)} \frac{\sqrt{3}}{2}$$

### 3.3 Direct Wiring of `AnimeMeshConfig.skirt_clearance_mm`
Let $c_m = \left(\frac{\text{skirt\_clearance\_mm}}{1000.0}\right) \cdot s$.
The parameterized radii are formulated directly from the anatomical base boundary plus clearance:
$$R_{x,\text{waist}} = (0.193 \cdot s) + c_m$$
$$R_{y,\text{waist}} = (0.157 \cdot s) + c_m$$
$$R_{x,\text{hem}} = (0.295 \cdot s) + c_m$$
$$R_{y,\text{hem}} = (0.237 \cdot s) + c_m$$

Under default configuration (`skirt_clearance_mm = 15.0`, $s = 1.0$):
- $R_{x,\text{waist}} = 0.193 + 0.015 = \mathbf{0.208\,\text{m}}$
- $R_{y,\text{waist}} = 0.157 + 0.015 = \mathbf{0.172\,\text{m}}$
- $R_{x,\text{hem}} = 0.295 + 0.015 = \mathbf{0.310\,\text{m}}$
- $R_{y,\text{hem}} = 0.237 + 0.015 = \mathbf{0.252\,\text{m}}$
- $y_c = \mathbf{-0.016\,\text{m}}$
- $A_{\text{waist}} = 0.006\,\text{m}$

## 4. Silhouette Aesthetics & Self-Intersection Proof ($A_{\text{hem}} < A_{\text{critical}}$)

### 4.1 A-Line Anime Silhouette Proportion
The characteristic Bishoujo A-line flare ratio is defined as $\Phi = \frac{R_{\text{hem}}}{R_{\text{waist}}}$.
- **X-axis Flare Ratio**: $\Phi_x = \frac{0.310}{0.208} = \mathbf{1.490}$
- **Y-axis Flare Ratio**: $\Phi_y = \frac{0.252}{0.172} = \mathbf{1.465}$

Compared to the original generator values ($\Phi_x = \frac{0.285}{0.185} = 1.541$, $\Phi_y = \frac{0.235}{0.155} = 1.516$), the flare ratio is within $3\%$ of the original aesthetic. The skirt maintains a clean, triangular Bishoujo school-idol silhouette without becoming an overly puffy bell/hoop skirt.

### 4.2 Self-Intersection Analysis ($A_{\text{critical}}$)
For a 2D closed curve parameterized by $\theta \in [0, 2\pi)$ with $N$ sinusoidal pleats:
$$r(\theta) = R + A \sin(N\theta)$$
In polar coordinates, $r(\theta) > 0$ is single-valued for all $\theta \in [0, 2\pi)$ as long as $A < R$.
For discrete polygon sampling with $M = 48$ vertices and $N = 16$ pleats:
The radial scale factor is $r_{\text{scale}} = 1.0 + \frac{A}{R_x} \sin(16\theta)$.
At the deepest valley trough, $\sin(16\theta) = -\frac{\sqrt{3}}{2}$.
Self-intersection (polygon inversion through center) occurs if and only if $r_{\text{scale}} \le 0$:
$$1.0 - \frac{A_{\text{critical}}}{R_x} \frac{\sqrt{3}}{2} = 0 \implies A_{\text{critical}} = \frac{2}{\sqrt{3}} R_x \approx 1.1547 \cdot R_x$$

At the hem ($R_x = 0.310\text{m}$):
$$A_{\text{critical}} = \frac{2}{\sqrt{3}} \times 0.310\,\text{m} = \mathbf{0.35796\,\text{m} = 357.96\,\text{mm}}$$

Our specified hem pleat amplitude is $A_{\text{hem}} = 0.022\text{m} = 22.0\text{mm}$.
Therefore:
$$\frac{A_{\text{hem}}}{A_{\text{critical}}} = \frac{22.0\,\text{mm}}{357.96\,\text{mm}} = \mathbf{6.15\%}$$
$$\text{Safety Factor} = \frac{A_{\text{critical}}}{A_{\text{hem}}} = \mathbf{16.27\times}$$
Zero polygon edge intersections occur across all rings, mathematically guaranteeing **zero self-intersection**.
