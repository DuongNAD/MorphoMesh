### 1.2 Root Cause Analysis: Cache Masquerading & API Key Bypass Defect

Investigation of the failure revealed a serious design defect and invariant bypass in `generator.py`:

1. **Premature Cache Lookup in `generate_plant`**:
   In `teamwork_projects/vegetation_library/vegetation_pipeline/generator.py` (lines 1395–1408):
   ```python
   # 3. Initialize Meshy engine
   meshy_gen = MeshyGenerator(config=generator_config)

   # 4. Check disk cache if not force_regenerate
   if not force_regenerate and not meshy_gen.config.force_regenerate and meshy_gen.config.use_cache:
       cached_asset = meshy_gen.check_cache(species_obj, target_dir=out_path)
       if cached_asset is not None:
           return cached_asset

   # 5. Mode: Explicit Meshy
   if mode == "meshy":
       api_key = meshy_gen.resolve_api_key()
       if not api_key:
           raise RuntimeError("MESHY_API_KEY API key environment variable is not set")
       return meshy_gen.generate(species_obj, output_dir=out_path, force_regenerate=force_regenerate)
   ```
   Step 4 executes **before** Step 5 (`if mode == "meshy"`).

2. **Unvalidated Cache Provenance in `MeshyGenerator.check_cache`**:
   In `generator.py` (lines 438–525), `check_cache` searches candidate directories including `target_dir` (which defaults to `./output/<category>/<species_id>`). If `{species_id}.glb` and four texture files exist, it returns `RawAsset(source="cached")` **without checking whether the asset was actually generated by Meshy AI**. It accepts procedurally generated assets from previous runs or tests.

3. **Empirical Reproduction of Cache Masquerading**:
   Executing `generate_plant` with `mode="meshy"` and environment keys stripped:
   ```python

   os.environ.pop('MESHY_AI_API_KEY', None)
   asset = generate_plant(oak, mode='meshy')
   ```
   Output:
   ```
   Asset source: cached
   Asset GLB: output\broadleaf_trees\veg_tree_oak_01\veg_tree_oak_01.glb
   Asset metadata source: procedural
   ```
   **Observation**: When `output/broadleaf_trees/veg_tree_oak_01` exists on disk, `generate_plant(oak, mode="meshy")` returns the cached **procedural** asset, completely bypassing credential checks and failing to raise the required `RuntimeError`.

4. **Test Suite Flaw**:
